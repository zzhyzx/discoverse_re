# 纠偏数据混合微调

入口：`policies/smolvla/train_sim_recovery_ur5.py`。仅离线仿真数据训练，不连接实机、不上传Hub。

## 本轮配置

- 源权重：`sim_ur5_padding_fix_from023000_20261021/checkpoints/024000`。
- 原数据：`data/ur5_lift_sim_v21`，270条训练/30条验证。
- 纠偏数据：`data/ur5_recovery_demos_20261025_v21`，41条训练/4条验证。
- 从两个训练子集按70%/30%的概率抽取帧，源内均匀、有放回；实际抽样索引另存sampling_indices.json。不是按episode数量机械拼接，也未实施阶段重加权。
- 新建AdamW优化器；学习率峰值1e-5，50步预热，余弦衰减至2.5e-6。额外1000步，batch=4，每250步验证并保存。
- 保留源模型归一化统计（原训练子集统计），不让微调同时改变输入输出的物理尺度。验证集从不参与训练抽样或统计量计算。
- 继续冻结视觉编码器，训练参数配置继承源模型；chunk=50，n_action_steps=10，AMP关闭，保留action_is_pad修复。
- 两个验证子集分别统计，每条轨迹最多40个均匀时刻，固定flow-loss随机种子；记录更新前step0与更新后的结果。

这是使用新数据分布的微调，不是原优化器的断点续训。检查点000250代表额外250步，不是原模型总训练仅250步。

## 命令

项目根目录、discoverse环境下执行；output必须是新目录：

```bash
python policies/smolvla/train_sim_recovery_ur5.py --smoke \
  --output policies/smolvla/checkpoints/recovery_mix_smoke_new

python policies/smolvla/train_sim_recovery_ur5.py --steps 1000 \
  --output policies/smolvla/checkpoints/recovery_mix_new
```

--smoke运行两次更新并验收有限损失/梯度、参数改变、保存重载与归一化不变。正式运行完成后生成COMPLETE.json；仅出现检查点目录不等于整轮运行已完成。

本轮正式输出：`policies/smolvla/checkpoints/sim_ur5_recovery_mix_20261025`。
抽样、数据划分与初始化记录：mixed_training.json。
训练与验证日志：metrics.jsonl。

额外1000步训练已完成。COMPLETE.json确认参数更新、最终权重重载成功、归一化不变；000250、000500、000750、001000均已保存。

## 注意

- 当前入口不提供优化器断点续训；不能用旧train_sim_ur5.py的resume直接接续这个混合实验。检查点保存了训练状态，若需中断恢复应实现并验证混合抽样进度的恢复。
- train_config.json的dataset字段为兼容旧配置结构，只描述原数据源；实际混合设置以mixed_training.json为准。
- 本轮没有修改原300条数据、新45条数据、源024000权重或实机控制代码。
- 验证损失降低不能证明抓取成功率提高。后续须在同样的无偏移及6/8/10cm偏移条件下对比，并补充独立布局的闭环测试。
- 仅改变数据混合和微调设置，没有同时放宽闭环控制限速，便于分析新增示范的作用；严格因果对照还应添加同样更新预算的原数据单独微调组。
