# 失败起点的规则专家对照（2026-10-25）

## 结果

对上一轮65次固定朝向测试中的全部43个失败样例，从相同初始状态重新执行规则专家：**43/43成功**。这是对失败子集的可行性诊断，不是随机任务成功率，也不是实机测试。

| 失败子集 | 专家成功 |
|---|---:|
| 无偏移基线 | 1/1 |
| 6 cm四方向 | 13/13 |
| 8 cm四方向 | 15/15 |
| 10 cm四方向 | 14/14 |

模型此前碰撞停止的 `x_minus10/001` 也成功。专家全部在4.43至6.07秒仿真时间内结束。86段视频完整解码，帧数与日志一致；全部日志末尾的稳定抬升状态持续至少1秒。

## 对照方法与边界

- 输入：`data/smolvla_translation_large_20261022/translation_summary.json`，按source追溯每个原始样例，包括续测目录。
- 同一物块位置、零yaw、初始化方法、30Hz控制与记录、重力补偿、0.9 rad/s每轴关节目标变化率上限、20秒超时、碰撞判据和成功判据。
- 逐例验证六关节角、夹爪归一化反馈、物块位置与原样例一致；这些数值差为0，TCP差最大约5.74e-16 m。
- 从记录的初始偏移姿态开始，不回home，不筛除任何失败位置。保留采集专家自身的上移至桌面上方24cm、横移对齐、下降、闭合、抬升路径。
- 复用采集Expert的到位条件、IK和0.8秒闭合等待。专家每帧更新，使用准确物块坐标；模型每10步刷新动作块。这些是控制策略的差别，因此不能把结果差异单独归因于某一因素。
- 限速针对目标变化率，不是实际关节速度安全保证。float32日志计算得到最大0.9000063 rad/s，属于量化误差。
- 闭合时专家水平误差中位数0.0332 cm，最大0.0773 cm；TCP比物块中心高1.74至2.30 cm。需要结合夹爪几何解释高度，不能当作实机通用抓取参数。
- 输出全部标记 `diagnostic_only=true`、`training_eligible=false`，不会自动加入训练数据。无实机连接或模型训练。

## 解释

这些失败起点并非因为任务本身不可达，或当前重力补偿、接触参数、限速让任何控制器都无法完成。更应优先排查策略的定位、对齐后下降与闭合衔接、动作块执行和训练状态覆盖。

本轮不能证明数据质量一定有错，也不能完全排除控制跟踪对不同轨迹的影响。专家拥有物块真值，而模型依赖图像，尚不能区分视觉定位不足和阶段切换不足。不能将专家43/43解释为模型也应无需额外训练达到同样效果。

建议下一步在独立布局与随机种子上采集相同类型的偏移纠正示范，适当增加关键下降/闭合阶段的训练采样，再用固定对照测试评估。不要将这43个诊断样例直接用于训练后，再把同一组结果称为独立泛化验证。

## 文件与重跑

入口：`scripts/ur5_expert_failure_check.py`。
结果：`data/ur5_expert_failure_check_20261025/summary.json`。
每例：`initialization.json`、`obs_action.json`、`expert_trace.json`、`cam_0.mp4`、`cam_1.mp4`。

在项目根目录执行，output必须是新目录，原测试不会覆盖：

```bash
MUJOCO_GL=egl python scripts/ur5_expert_failure_check.py \
  --reference data/smolvla_translation_large_20261022 \
  --output data/ur5_expert_failure_check_repeat
```

脚本复用现有仿真评估模块，因此仍需discoverse训练环境的依赖，但不会加载策略权重或创建任何RTDE接口。日志中初始化辅助函数会打印state0；实际进入评估后从state1开始，并未执行回home动作。
