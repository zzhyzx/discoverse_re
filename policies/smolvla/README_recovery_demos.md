## 实际教给模型什么

从带水平偏移的张开夹爪姿态出发，规则专家先升至桌面上方24cm，再横移对齐、下降、闭合、抬升并保持。不是贴桌横向纠正，也未包含“先故意夹空，再张开重新抓”的恢复示范。

动作仍为6个绝对关节目标（rad）与0/1夹爪指令；状态为6个实际角与仿真夹爪反馈。cam_0对应d436正面、cam_1对应d405腕部；30Hz，重力补偿开启。每轴关节目标变化率上限0.9 rad/s，与最近评估一致，不是实际关节速度保证。

每条原始轨迹保存expert_trace.json中的阶段。全批阶段帧数：上移/对齐1556，预抓下降690，抓取高度下降467，闭合等待1080，抬升1326，保持1611。之后可按阶段采样，但本次没有重采样或破坏时间顺序。

新增轨迹不从统一home开始，因此start_reference_rad记录本条实际初始角，home_reference_rad另行保留。不要用旧home初始化断言拒绝这些轨迹，也不要在部署时把某个随机偏移起点当成固定home。

## 重新采集 / 续采

在项目根目录，output使用新目录：

```bash
MUJOCO_GL=egl python scripts/ur5_collect_recovery_demos.py \
  --output data/ur5_recovery_repeat --stop-after 8

MUJOCO_GL=egl python scripts/ur5_collect_recovery_demos.py \
  --output data/ur5_recovery_repeat --resume --stop-after 48
```

已记录完成的尝试不会重采；恢复时跳过相同次数的场景reset以保持布局序列。不完整的尝试目录不会被覆盖，会报错要求检查；不要删除已有合格数据。更换seed时必须使用新目录。

## 后续训练边界

尚未开始训练，也未把数据合并进原训练入口。这是第一批针对性补充，不代表数量已足够或已证明收益。建议与原训练子集混合并保留验证划分，避免只训练这批而遗忘完整任务。对照原模型与加入新增数据后的模型，使用相同闭环条件；最终泛化结论另用新布局测试。

空夹恢复、旋转扰动、对角方向以及运动途中受到扰动目前仍未覆盖。
